探测方案

语言维度越多，判定越稳。快速档仅用英语。
原理：向端点发送 10 类「随机说一个数/词」的单 token 问题（温度=1），构建答案分布指纹， 与论文实测的 165 个参考模型比对 Jensen-Shannon 散度。判定阈值：≤0.25 相符 · 0.25–0.35 存疑 · >0.35 高概率不符。
尚无检测任务。到「检测」页连接中转站并选择模型开始。

这是什么

ModelProof 用于检验 API 中转站 / 代理商是否在用其它模型冒充你所购买的模型（俗称“注水”）。 方法来自 Tomáš Bruckner（布拉格经济大学）的论文 One Token Is Enough: Fingerprinting and Verifying Large Language Models from Single-Token Output Distributions（arXiv:2607.10252, 2026）。

原理

每个模型对“随便说一个 1–100 的数字”这类问题都有独特而稳定的偏好分布：GPT 系偏爱 42、73， 其它家族各有各的习惯，连“正面/反面”“喜欢的颜色”都带着家族口音。把 10 类单 token 问题 × 4 种语言的答案分布拼在一起，就得到该模型的行为指纹。论文实测：同模型不同采样之间平均 JSD ≈ 0.14，跨服务商 ≈ 0.23，而不同模型的中位数距离是 0.46；完整 40 维度电池的验证 AUC=0.971、EER=7.3%。

如何解读结果

≤ 0.25与声称型号相符 —— 在跨服务商的正常波动范围内
0.25 – 0.35存疑 —— 可能只是换了上游部署/量化版本，也可能是轻量替换
> 0.35高概率不符 —— 行为学上无法用声称型号解释
「最像模型排行」会给出行为上最接近的已知模型：如果榜首不是你买的那个，就是最直接的注水证据。

局限

这是行为学证据而非密码学证明。以下情况会造成干扰：端点注入自己的系统提示词、推理型模型隐藏思维链、 服务端缓存重复应答、以及参考库未覆盖的小众模型（此时只给最近邻排行）。应用会对这些信号给出提示。
